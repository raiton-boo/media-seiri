# 機能: 地図(map)

## 1. 目的

GPS 付きの写真・動画を、地図の上にピンで表示し、「どこで撮ったか」から、写真をたどれるようにする。

## 2. 関連する要件

G-01〜G-05, C-01, C-07, W-01
仕様書: §15, §16

## 3. 表示

- GPS を持つファイルの位置に、ピンを表示する [G-01]。
- 近い位置のピンは、クラスタ(まとまり)にして、件数を表示する [G-02]。
  - 拡大すると、クラスタが分かれる。
  - クラスタをクリックすると、その範囲に拡大する。
- **背景地図**を表示する [G-03]。
- 対象は、取り込み済みの全データ(通常の実行のみ。dry-run は含まない) [G-05]。

## 4. 操作

| 操作               | 内容                                                                                         |
| :----------------- | :------------------------------------------------------------------------------------------- |
| ピンをクリック     | その位置の写真を、サムネイルの一覧(ポップアップ)で表示する。クリックで、アルバムの拡大表示へ |
| クラスタをクリック | その範囲に、拡大する                                                                         |
| 範囲の選択         | 地図の現在の表示範囲の写真を、アルバムで一覧する                                             |
| 絞り込み           | 年・月・カメラ・種別で絞る(アルバムと同じ条件)                                               |
| 期間の指定         | 期間(開始〜終了)を指定して、その期間のピンだけを表示する。(仮)                               |

## 5. GPS の取得元

- 優先: ファイル本体のメタデータの GPS。
- 本体にない場合: Takeout の json の `geoData`(`zip-handling.md`)。
- (0, 0)は、無効として扱い、「GPS なし」にする。
- **位置の推定は行わない** [G-04]。

## 6. GPS がないファイル [G-04]

- 地図には、表示しない。
- 「GPS なし」として、一覧にまとめる(件数と、アルバムへのリンク)。
- 地図の画面から、「GPS なしのファイルを見る」で、アルバムに移れる。

## 7. 背景地図 [C-11, G-03]

- 背景地図は、**オンラインの地図タイルを取得して表示する**(決定)。
  - 画面は、プログラムが動かすローカルの Web ページ。ブラウザが、地図のタイルを、外部のタイルの提供元から取得する。
  - 家の PC も、ネットワークにつながっている前提。
- 外部に送られるのは、「見ている範囲のタイルの要求」だけ。写真・台帳のデータは、送らない [C-01, C-11]。
- タイルの提供元は、設定で変更できる。既定は、**国土地理院の地理院タイル**(撮影場所が、日本国内だけのため)。OpenStreetMap は、設定で選べる任意の提供元とする。ライブラリは MapLibre GL JS(`tech-selection.md` §7)。
- 提供元の鍵(API キー)が必要な場合は、ソースコードに書かず、環境変数・設定ファイルで与える(`docs/rules/CODING-STYLE.md`)。
- 地図の出典の表記(著作権表示)を、画面に出す。
- ネットにつながらない場合は、背景を出さず、ピンと座標の一覧だけを使えるようにする。
- オフライン対応は、必要になったときに、検討する(スコープ外)。

## 8. 性能

- ピンの数は、数万〜10 万件になりうる。
- クラスタの計算は、表示範囲とズームに応じて、必要な分だけ行う(サーバー側または画面側)。
- 地図の移動・拡大が、もたつかないこと。(目標の数値は、技術選定のあとで決める)
- ピンの位置データは、台帳の `media_metadata`(`gps_lat`, `gps_lon`)から読む。

## 9. 閲覧専用ビューアでの動作

- 家の PC でも、同じ地図が使える [W-01]。ネットワークにつながっていれば、背景地図も表示される。
- ネットにつながっていない場合は、背景を出さず、ピンと座標の一覧は使える。

## 10. 受け入れ条件

- GPS 付きのファイルが、ピンで表示されること。
- 近いピンが、クラスタ化されること。
- 背景地図が表示されること。
- ピン・クラスタから、写真の一覧へたどれること。
- GPS がないファイルが、地図に出ず、「GPS なし」として一覧できること。
- dry-run の結果が、含まれないこと。
- 数万件のピンでも、操作が重くならないこと。
