# 機能: Web 画面と閲覧専用ビューア(web-viewer)

## 1. 目的

- 取り込みの結果を、Web 画面で閲覧する(アルバム、地図、統計、各一覧、実行状況)。
- 画面の台帳とサムネイルは、この Mac では `data/` の正本を、家の PC では、ライブラリのコピーを使う(`album.md` 15 章)。
- 家の PC(Windows など)でも、ドライブをつなぐだけで、同じ画面を使えるようにする。
- Web は、**どの場合も、読み取り専用**。ファイルの書き込み・コピー・削除は、行わない。

## 3. 画面は1種類、台帳の取得元だけが違う

Web は、書き込みの操作を持たないので、動作モードを分ける必要がない。どの PC でも、同じ画面を使う。違うのは、台帳の取得元だけ。

|                                    | この Mac(開発環境)    | 家の PC など(macOS / Windows)                                     |
| :--------------------------------- | :-------------------- | :---------------------------------------------------------------- |
| 台帳                               | 作業用の台帳(`data/`) | ドライブ内のスナップショット(読み取り専用)                        |
| 閲覧(アルバム・地図・統計・各一覧) | ○                     | ○                                                                 |
| 実行状況のリアルタイム表示         | ○(CLI の実行中のみ)   | ×(実行は、この Mac の CLI だけ)                                   |
| 台帳の鮮度                         | 常に最新              | 最後のスナップショットの時点                                      |
| 配布                               | プロジェクトから起動  | OS ごとの単体の実行ファイルを、ドライブの `viewer/` に置く [W-02] |

- 本機(自分の PC)からのみ接続を受け付ける [N-03]。外部には、公開しない。
- 外部への通信は、背景地図のタイルの取得だけ [C-11]。

| :--------------------- | :------------------------------------------------------------------------------------------------------------------------ | :------------------- |
| ダッシュボード         | ライブラリの概要、実行状況、最近の実行                                                                                    | 5章                  |
| アルバム               | 入口(最新の年の机)/ 机(年・月・できごと)/ すべて / 検索・絞り込み / 拡大表示 / スライドショー / カレンダー / 自動アルバム | `album.md`           |
| 地図                   | GPS のピンとクラスタ                                                                                                      | `map.md`             |
| 統計                   | 月別・年別、カメラ別、時間帯                                                                                              | `statistics.md`      |
| 重複比較               | 採用とスキップの比較(確認のみ)                                                                                            | `dedupe.md`          |
| 日付フォールバック一覧 | 本体から日付が取れなかったファイル                                                                                        | `date-resolution.md` |
| エラー一覧             | 取り込み中に起きたエラー                                                                                                  | 6章                  |
| 実行履歴               | 実行ごとの記録(dry-run を含む)                                                                                            | 7章                  |

## 5. ダッシュボード

- ライブラリの情報: 名前(ID)、場所(ドライブ)、ファイル数、総サイズ、最終の取り込み日時。
- スナップショットの日時(他の PC では、「どの時点の情報か」を明示する)。
- 実行中の実行があれば、進捗・件数・処理中のファイル・直近のログ(リアルタイム) [L-03]。
- 最近の実行の一覧と、結果の件数。
- 注意が必要な項目へのリンク: エラーの件数、日付フォールバックの件数、日付なし(`_unknown`)の件数。

## 6. エラー一覧 [L-04]

### 6-1. 列

| 列       | 内容                                         |
| :------- | :------------------------------------------- |
| コード   | `HASH_MISMATCH` など(仕様書 §14)             |
| ファイル | 元の場所(ZIP 内なら、ZIP のパスと、中のパス) |
| 詳細     | エラーの内容                                 |
| 実行     | どの実行で起きたか                           |
| 日時     | 発生した時刻                                 |
| 修復     | 試した手順と結果(破損の場合)                 |

### 6-2. 操作

- コードごと・実行ごとに、絞り込める。
- ファイルをクリックすると、詳細(サムネイル、メタデータ、修復の経過)を表示する。
- エラーの一覧を、CSV で書き出せる。(仮)
- エラーの状態を、Web から変更する操作は、持たない。再実行で、結果が変わる。

## 7. 実行履歴

- 実行(run)ごとに、ソース・開始/終了の日時・状態・件数を、一覧する。
- dry-run は、「dry-run」の印つきで、表示する [X-03]。
- 実行をクリックすると、その実行の、採用・スキップ・フォールバック・エラーの一覧を表示する。

## 8. リアルタイム更新 [L-03]

- CLI が書き込んだ内容を、Web に、リアルタイムで反映する(この Mac のみ)。
- 実行中の進捗・件数・ログを、画面を再読み込みせずに、更新する。
- 通信の方式は、技術選定で決める。

## 9. 閲覧専用ビューアの配布と起動 [W-02]

- 配布物: OS ごと(macOS / Windows)の、**単体の実行ファイル**。ドライブの `viewer/` に置く。
  - 実行環境(Python や Node など)の、インストールを要さない。
- 起動の流れ:
  1. ドライブをつなぐ。
  2. `viewer/` の、自分の OS 用の実行ファイルを開く。
  3. ライブラリを、実行ファイルの場所から、自動で探す(または、パスを指定する)。
  4. ブラウザが開き、ダッシュボードが表示される。
- ライブラリの場所は、台帳が相対パスのため、ドライブ文字・マウント先が変わっても、動く [W-04]。
- 台帳のスナップショットが古い場合は、「最終の更新が、〇月〇日です」と表示する。

## 10. 表示と使い勝手

- 画面の言語は、日本語。
- 主な利用環境は、PC のブラウザ(デスクトップ)。スマートフォンの最適化は、スコープ外。(仮)
- ワイヤーフレーム(Artifact)で、画面のレイアウトを確認する。

## 11. セキュリティ

- 本機(`127.0.0.1`)からのみ接続を受け付ける [N-03]。
- 認証は、設けない(本機のみのため)。
- 外部への通信は、背景地図のタイルの取得だけ [C-11]。写真・台帳のデータは、送らない。
- 台帳に個人情報が入るため、台帳のスナップショットを持つドライブの扱いに、注意する。

## 12. 受け入れ条件

- Web から、ファイルの書き込み・コピー・削除ができないこと。
- すべての画面が、この Mac と、他の PC(スナップショット)の両方で使えること。
- 閲覧専用ビューアの実行ファイルが、実行環境のインストールなしで、Windows と macOS で起動すること。
- ドライブ文字が変わっても、ビューアが、ライブラリを開けること。
- CLI の実行中の進捗が、この Mac の Web にリアルタイムで表示されること。
- エラー一覧が、コード・実行で絞り込めること。
- 本機以外から、接続できないこと。
- ネットにつながらなくても、背景地図以外の画面が使えること。
