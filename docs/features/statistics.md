# 機能: 統計(statistics)

## 1. 目的

取り込み済みの写真・動画の、件数や傾向を、グラフで見られるようにする。

## 2. 関連する要件

S-01〜S-04, A-07
仕様書: §16-3

## 3. 対象

- 取り込み済みの全データ(通常の実行のみ。dry-run は含まない) [S-04]。
- 重複としてスキップしたファイルは、数えない(ライブラリに実在するファイルを数える)。
- RAW+JPEG の同名ペアは、「ファイル数」では、別々に数える。「撮影の枚数」(グループ数)でも見られるようにする。(仮)

## 4. 画面の構成

### 4-1. 期間別の件数 [S-01]

- **月別**と**年別**を、切り替えて表示する。
- 棒グラフ。期間ごとの件数(写真・動画・RAW の内訳つき)。
- 棒をクリックすると、その期間のアルバムに移る。
- 月別は、年を選んで表示する(その年の1〜12月)。または、全期間を連続して表示する。(仮)

### 4-2. カメラ別の内訳 [S-02]

- カメラの機種ごとの件数(円グラフまたは横棒グラフ)。
- 機種が不明なもの(メタデータがない)は、「不明」にまとめる。
- メーカーの表記ゆれ(`Canon` / `CANON` など)は、正規化してまとめる。(仮)
- 項目をクリックすると、その機種でアルバムを絞り込む。

### 4-3. 撮影時間帯の分布 [S-03]

- 0〜23 時ごとの件数(棒グラフ)。
- 時刻は、決定したローカル時刻を使う。
- 時刻が取れていない(精度が `full` 未満の)ファイルは、対象外にして、その件数を注記する。

### 4-4. 全体の概要

- 総ファイル数、種別ごとの件数、総サイズ。
- 期間(最初と最後の撮影日)。
- 日付の精度ごとの件数(`full` / `date` / `month` / `year` / `none` / `invalid`)。
- 日付フォールバックの件数(取得元の種別ごと)と、一覧へのリンク。
- GPS 付き・なしの件数(地図へのリンク)。

## 5. 日付が不明なファイルの扱い

- 期間別の件数では、年月が取れたものだけを、期間ごとに数える。
- 年月が取れていないもの(年のみ、日付なし、日付が不正)は、「不明」として、別の棒にまとめる。合計が、全体の件数と一致するようにする。

## 6. 絞り込み

- 種別(写真 / 動画 / RAW)、ソース(実行)で、集計を絞り込める。(仮)
- 絞り込みは、すべてのグラフに反映される。

## 7. 性能

- 数万〜数十万件の集計を、すぐに表示する。
- 集計は、台帳(`media_metadata`、`library_files`)を、データベース側で集計して行う。
- 画面を開くたびに、全件を読まない。必要なら、集計結果を保持して、実行の完了時に更新する。(仮。技術選定のあとで決める)

## 8. 閲覧専用ビューアでの動作

- 家の PC でも、同じ統計を、スナップショットから表示できる [W-01]。
- 原本のドライブが、接続されていなくても、統計は、見られる(台帳だけで、計算できるため)。

## 9. 受け入れ条件

- 月別・年別の件数が、切り替えて表示されること。
- カメラ別の内訳が、表示されること。
- 時間帯の分布が、表示されること(時刻が取れていないものを、除いた件数の注記つき)。
- 日付が不明なファイルが、「不明」として、集計に含まれること(合計が合う)。
- dry-run の結果が、含まれないこと。
- グラフの項目から、アルバムの絞り込みに移れること。
