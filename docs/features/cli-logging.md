# 機能: CLI の表示とログ(cli-logging)

## 1. 目的

取り込みの進み具合と、起こっていることを、ターミナルで逐次わかるようにする。見た目にもこだわる。ログは、ファイルにも、台帳にも残す。

## 2. 関連する要件

L-01〜L-05, N-05
仕様書: §13 / ER: `events`, `errors` / フロー: `flows.md` 6章

## 3. 出力の種類

| 出力           | 内容                                             | 向いている用途                       |
| :------------- | :----------------------------------------------- | :----------------------------------- |
| **ライブ表示** | 画面を書き換えながら、進捗とカウンターを表示する | 対話的に、実行を見ているとき         |
| **ログの行**   | 1イベント1行で、流れるように出力する             | 画面の記録、ファイルへのリダイレクト |
| サマリー       | 実行の最後に、結果をまとめて表示する             | 結果の確認                           |

- 標準出力が端末(TTY)でない場合(リダイレクト、パイプ)は、ライブ表示をやめて、ログの行だけを出す。
- 色は、端末が対応している場合だけ使う。`NO_COLOR` が設定されていれば、使わない。

## 4. ライブ表示の構成(案)

```text
┌──────────────────────────────────────────────────────────────┐
│  file-seiri  ingest   run #12                                │
│  Backup-HDD ➜ Library-2024      経過 00:42:17   残り ~01:05  │
├──────────────────────────────────────────────────────────────┤
│  進捗   ████████████░░░░░░░░░░  58%    9,060 / 15,610        │
│  容量   72.1 GB / 124.3 GB      速度  61.4 MB/s              │
├──────────────────────────────────────────────────────────────┤
│  採用 8,420   重複 560   フォールバック 41   エラー 2         │
├──────────────────────────────────────────────────────────────┤
│  処理中  2019/DCIM/100CANON/IMG_4821.CR3                     │
│          ハッシュ → コピー → 検証                             │
├──────────────────────────────────────────────────────────────┤
│  14:02:11 WARN  日付フォールバック(filename): IMG_20190405.jpg │
│  14:02:12 ERROR HASH_MISMATCH: IMG_4001.JPG                   │
│  14:02:13 INFO  重複スキップ: IMG_3999.JPG                    │
└──────────────────────────────────────────────────────────────┘
```

(見た目は、案。ワイヤーフレームで、確認する)

- 起動時に、ASCII のロゴ・バナーを表示する。(仮)
- 処理中のファイルが、どの段階か(スキャン / ハッシュ / コピー / 検証 / サムネイル)を表示する。
- 直近のログを、下部に流す。
- ソースが複数ある場合は、全体の進捗(何個目のソースか)も表示する。

## 5. ログのレベルと内容

| レベル | 内容の例                                               |
| :----- | :----------------------------------------------------- |
| DEBUG  | 処理の細部(ハッシュ値、キャッシュのヒット)             |
| INFO   | 取り込み・重複スキップ・サムネイル作成などの通常の記録 |
| WARN   | 日付フォールバック、ZIP の深さ超過、修復の試行など     |
| ERROR  | ハッシュ不一致、読み取り失敗、コピー失敗など           |

- 既定は INFO。`--verbose` で DEBUG、`--quiet` で WARN 以上だけを表示する。
- ライブ表示の下部には、WARN 以上を、優先して表示する。

## 6. ログの保存

- 各処理を**イベント**として、台帳(`events`)に記録する。CLI の表示も、Web の実行状況も、ここから作る [L-03]。
- 同じ内容を、ログファイルにも書き出す(`data/libraries/<ID>/logs/`)。実行ごとに、1ファイル [L-02]。
- ログファイルは、レベル・時刻・実行 ID・ファイルのパス・コード・メッセージを含む。
- ログの保存期間・サイズの上限は、設定できる(古いものは、圧縮または削除)。(仮)

## 7. ログの閲覧 [L-05]

| 操作                           | 内容                                         |
| :----------------------------- | :------------------------------------------- |
| `file-seiri logs`              | 直近の実行のログを表示する                   |
| `file-seiri logs --run <ID>`   | 指定した実行のログを表示する                 |
| `file-seiri logs --level WARN` | 指定したレベル以上を表示する                 |
| `file-seiri logs --follow`     | 実行中のログを、追いかけて表示する           |
| `file-seiri status`            | 現在の実行の状況と、ロックの保持者を表示する |

(コマンド名は仮)

- ログの閲覧は、主にターミナルで行う。結果の閲覧は、Web で行う [L-05]。

## 8. 中断と終了

| 状況                    | 振る舞い                                                                                                                                       |
| :---------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| Ctrl-C を、1回押した    | 今のファイルの処理を、終えて(または、安全な位置まで進めて)停止する。一時ファイルを削除し、状態を保存して、`interrupted` で終了する。再開できる |
| Ctrl-C を、続けて押した | 強制終了する。次回起動時に、一時ファイルを削除する                                                                                             |
| ドライブが抜けた        | エラーを記録し、中断する                                                                                                                       |

## 9. 終了コード(仮)

| コード | 意味                                         |
| :----- | :------------------------------------------- |
| 0      | 正常終了(エラーなし)                         |
| 1      | 完了したが、エラーのファイルがあった         |
| 2      | 実行できなかった(保存先の検査・容量不足など) |
| 130    | 中断(Ctrl-C)                                 |

## 10. サマリー

実行の最後に、次を表示する。

- 検出・採用(コピー)・重複スキップ・日付フォールバック・エラー・対象外の件数
- コピーしたサイズ、所要時間、平均の速度
- エラーの内訳(コードごと)
- 次にやること(「Web で結果を確認してください」など)
- `dry-run` の場合は、その旨と、容量の見積り(`dry-run.md`)

## 11. 受け入れ条件

- 処理中のファイル・進捗・件数が、逐次表示されること。
- 標準出力が端末でないとき、ライブ表示が出ず、ログの行だけが出ること。
- すべてのログが、台帳とログファイルに記録されること。
- Web で、実行中の状況が、リアルタイムに見られること。
- Ctrl-C で、一時ファイルが削除され、再開できる状態で終了すること。
- 実行の最後に、サマリーが表示されること。
