# 機能: アルバム(album)

## 1. 目的

取り込み済みの写真・動画を、**眺める・探す・思い出す**。1.5 万枚(将来は 10 万枚規模)でも、すばやく移動でき、「あの日」に出会えるようにする。Web は読み取り専用で、写真のファイルには、触れない。

## 2. 関連する要件

[アルバム](../requirements.md#a-01)、[地図](../requirements.md#g-01)、[統計](../requirements.md#s-01)、[閲覧専用ビューア](../requirements.md#w-01)、[オンラインの地図タイル](../requirements.md#c-11)

## 3. 画面と流れ

| 画面               | 役割                                                          | 要件       |
| :----------------- | :------------------------------------------------------------ | :--------- |
| **入口**           | 最新の年の机。上に「去年の今日」「今日の一枚」                | [入口は最新の年の机](../requirements.md#a-01)、[去年の今日・今日の一枚](../requirements.md#a-12) |
| **机(年)**         | その年の、月ごとの代表の 1 枚(12 枚)を、机に広げる            | [年・月・できごと・すべてのズーム](../requirements.md#a-02)〜[できごとの自動まとめ](../requirements.md#a-04) |
| **机(月)**         | その月の、できごとの束を置く                                  | [できごとの自動まとめ](../requirements.md#a-04)       |
| **机(できごと)**   | そのできごとの写真を、広げる                                  | [机の配置](../requirements.md#a-03)、[できごとの自動まとめ](../requirements.md#a-04) |
| **すべて**         | マソンリー(既定)/ 行ぞろえ。全部の写真から探す                | [マソンリーと行ぞろえ](../requirements.md#a-05)       |
| **検索・絞り込み** | 検索の札・付箋のチップ・右の引き出し                          | [検索](../requirements.md#a-06)、[絞り込み](../requirements.md#a-07) |
| **拡大表示**       | 1 枚を大きく。情報・地図・フィルムストリップ                  | [拡大表示](../requirements.md#a-08)       |
| **スライドショー** | 自動で順に表示                                                | [スライドショー](../requirements.md#a-09)       |
| **カレンダー**     | 日ごとの枚数を、ヒートマップで                                | [カレンダー](../requirements.md#a-10)       |
| **自動アルバム**   | 切り口ごとのまとまり                                          | [自動アルバム](../requirements.md#a-11)       |
| **状態**           | 未接続・見つからない・読み込み中・破損・日付不明・閲覧専用 PC | [状態の表示](../requirements.md#a-13)       |

```text
入口(最新の年の机)
  ├─ 机: 年 → 月 → できごと → 拡大表示 → スライドショー
  ├─ すべて(マソンリー / 行ぞろえ)→ 拡大表示
  ├─ 検索・絞り込み(どの画面にも効く)
  ├─ カレンダー → 日のできごと
  └─ 自動アルバム → すべて(絞り込み済み)
```

## 4. ズームと机

- ズーム(年 / 月 / できごと / すべて)は、画面上部の**時間の定規**と、パンくずで切り替える。
- **時間の定規**: 年の札が、枚数に比例した幅で並ぶ。現在の年は、月の棒グラフに開き、**つまみ**(「▼ 4月」)が、位置を示す。右に、並び順(新しい順 / 古い順)。
- 並び順の既定は、**新しい順**。年・月・できごとの順も、写真の順も、これに従う。

| ズーム   | 机に置くもの                                                                         |
| :------- | :----------------------------------------------------------------------------------- |
| 年       | 月ごとの代表の 1 枚(12 枚)。最多の月(新しい年の最新の月)は、大きく                   |
| 月       | できごとの束(重ねたポラロイド)。札に、日付・時間帯。角に枚数。「ほか小さなできごと」 |
| できごと | 写真(代表の枚数)。「もっと広げる」で +12 枚                                          |
| すべて   | マソンリー / 行ぞろえ(机ではない)                                                    |

## 5. 机の配置規則

- **格子の上に、傾けて置く**。重ならず、机の幅をはみ出さない。位置は、数値で決めうちにしない(仕様書 §16-8)。
- 格子は 4 列(検索結果は 3 列)、傾きは ±3° 以内、間隔は約 44〜52px。
- 一番大きい 1 枚は、2 列 × 2 行。写真の比率(4:3、3:4、1:1、3:2)を、順に割り当てる。
- 机の枚数が多いとき: 代表の枚数(既定 12)だけを置き、「もっと広げる」で、増やす。大量の写真は、「すべて」へ。
- 日付の札・テープなどの飾りは、写真に重ねても、読みを妨げない位置に置く。

## 6. すべて(マソンリー / 行ぞろえ)

- **マソンリー(既定)**: 縦長・横長・正方形が、比率のまま、列に流れる。月の見出し(シール)は、スクロールしても、上に残る。眺めるのに向く。
- **行ぞろえ**: 行の高さをそろえ、写真の幅が、比率で変わる。大量の写真を、すばやく探すのに向く。
- どちらも、**写真を切り抜かない**。日付の見出し(月・日)と、右端の**年・月のスクラバー**(年の札に、枚数)で、すばやく飛べる。
- 仮想スクロール(見えている分だけ読み込む)で、10 万枚でも軽く保つ。
- 日付が不明なもの: 各期間の末尾か、「日付なし」の自動アルバムにまとめる(§11)。

## 7. 検索

- 検索の札に入力すると、**日付・カメラ・場所・ファイル名**の候補が、件数つきで出る。
  - 例: 「場所: 新幹線の駅の近く(GPS)24」「名前: 新幹線\_0412.jpg 3」「日付: 2014年4月12日 61」
- 決めた条件は、**黄色の札(チップ)**になり、×で外せる。
- 結果は、代表の枚数だけ、机に広げる。件数が多いときは、「〇〇 件を一覧で」で、「すべて」(行ぞろえ)に切り替える。
- 場所の検索は、**GPS の座標のまとまり**を使う(地名への変換はしない)。

## 8. 絞り込み

| 条件         | 内容                                                    |
| :----------- | :------------------------------------------------------ |
| 種別         | 写真・動画・RAW                                         |
| カメラ       | 機種(メタデータがないものは「不明」)                    |
| GPS          | あり・なし                                              |
| 年           | 年                                                      |
| 日付の精度   | `full` / `date` / `month` / `year` / `none` / `invalid` |
| 日付の取得元 | 通常 / `json` / `filename`                              |
| ソース       | どの外付け(実行)から取り込んだか                        |

- 付箋のチップで、すばやく選び、細かい条件は、**右の引き出し**(チェックと件数)で選ぶ。
- 条件は、**すべてのズームに効く**(例: 「動画だけ」にすると、年の机も、月の机も、動画だけになる)。
- 有効な条件の数を表示し、「条件をすべてクリア」で戻せる。

## 9. できごと

- 取り込みの最後に、撮影時刻の空きと、場所から、**自動でまとめる**(仕様書 §16-6、`flows.md` 8 章)。
  - 時間差が 4 時間以上、または、距離が 5km 以上かつ時間差が 1 時間以上、で区切る(既定。設定可)。
  - 時刻のない写真(精度 `date`)は、日単位。3 枚未満は、「小さなできごと」。
- 代表の写真は、GPS つきを優先し、なければ、先頭の写真。
- 顔認識・AI は、使わない。

## 10. 去年の今日 / 今日の一枚

- **去年の今日**: 今日と同じ月日の、過去の年のできごと。最大 3 件。なければ、帯を出さない。
- **今日の一枚**: 日付ごとに固定の乱数で選ぶ。「別の 1 枚」で、選び直せる。

## 11. 自動アルバム(少数に絞る)

| アルバム           | 内容                                           |
| :----------------- | :--------------------------------------------- |
| できごと           | 自動でまとめたできごと(新しい順)               |
| 動画               | 種別が動画                                     |
| RAW                | 種別が RAW                                     |
| ライブフォト       | 同名グループ(`-video-paired` など)の写真と動画 |
| 場所のある写真     | GPS あり(地図へ)                               |
| カメラ別           | 機種ごと                                       |
| 日付フォールバック | 本体から日付が取れなかったもの                 |
| 日付なし           | `_unknown/日付なし` ほか、日付が不明なもの     |

- 自動アルバムは、増やしすぎない(Apple Photos で、重複する自動アルバムが、迷いの原因になった例を、避ける)。
- マイアルバム・お気に入りは、**ない**(書き込みを、持たないため)。

## 12. 拡大表示

- 前後の写真への移動(矢印キー)、下の**フィルムストリップ**、右の**情報の引き出し**。
- 情報: 撮影日時(精度・取得元)、カメラ、寸法・サイズ、種別、ハッシュ、パス、GPS(ミニ地図)、同名グループ(JPG / RAW / XMP)の切り替え。
- 「もっと見る」: この日の他の年、この場所の写真、同じできごと。
- 動画は、再生する(ブラウザで再生できる形式)。再生できない形式は、案内する。
- 原本が、ライブラリではなく、ソース側のコピーのときは、**「ソース側のコピーを表示中」**と示す(§15)。
- 削除・移動・名前の変更は、できない。

## 13. スライドショー

- できごと・検索結果・すべて(絞り込み済み)から、始められる。
- 速度(例: 3 秒)と、順序(新しい順 / シャッフル)を、選べる。停止・前後・終了(Esc)。進捗の棒と、次の写真の縮小を表示。
- 動画は、再生を終えてから、次へ。

## 14. カレンダー

- 年を選ぶと、**12 か月のカレンダー**に、日ごとの枚数が、濃さ(5 段階)で出る。
- 日を押すと、右に、その日の写真と、「その日の机を開く」「スライドショー」。「この年で多かった日」の上位も表示。
- 日付が不明なものは、載らない(自動アルバムの「日付なし」へ)。

## 15. サムネイルと、原本の探索

- **サムネイルの正本**は、この Mac の `data/`。ライブラリにコピーを置く(家の PC 用)。
  - この Mac では、**外付けのドライブを外していても、一覧は見られる**。
- **原本の探索**(`flows.md` 9 章): ライブラリの原本が接続中ならそれを表示。未接続で、同じ内容のコピー(ソース側。例: 取り込み元だった、この Mac のフォルダ)が接続中の場所にあれば、そこから表示する(サイズと更新日が一致する場合のみ)。なければ、サムネイルと、「〇〇のドライブを接続してください」。

## 16. 状態

| 状態               | 表示                                                                         |
| :----------------- | :--------------------------------------------------------------------------- |
| ドライブ未接続     | 注意の帯(「〇〇のドライブを接続してください」)。サムネイルの一覧は、見られる |
| 見つからない       | 条件の札を表示し、「条件を 1 つずつ外す」「すべてクリア」                    |
| 読み込み中         | スケルトン(Suspense)                                                         |
| 破損・読み取り不可 | プレースホルダーと、理由。「エラー一覧で詳しく見る」                         |
| 日付が不明         | 精度ごとのグループ。カレンダーには載らない                                   |
| 家の PC(閲覧専用)  | 最後のスナップショットの日時を表示。実行中の表示は、ない                           |

## 17. デザイン方針

[design.md](../design.md) に従う(ネオブルータリズム)。

## 18. 性能

- 10 万枚でも軽い: 仮想スクロール、見えている分だけの読み込み、集計は、台帳(SQLite)側で行う。
- できごとは、取り込みの最後に計算して、保存しておく(画面を開くたびに、計算しない)。
- サムネイルは、遅延読み込み。必要なものから、順に読む。

## 19. 閲覧専用ビューア(家の PC)

- 同じ画面を、台帳のスナップショットと、ライブラリのサムネイルのコピーで、動かす ([閲覧専用ビューア](../requirements.md#w-01))。
- 台帳は、読み取り専用で開く。書き込み・ロックは、しない。
- 背景地図(地図・拡大表示のミニ地図)だけ、ネットワークに接続する([オンラインの地図タイル](../requirements.md#c-11))。

## 20. 受け入れ条件

- 開くと、最新の年の机が表示され、上に「去年の今日」「今日の一枚」が出ること。
- 年 → 月 → できごと → 拡大表示へ、たどれること。定規のつまみ・パンくずで、戻れること。
- 机の写真が、**重ならず、机の幅をはみ出さない**こと(月数・枚数が変わっても)。
- 検索の候補が出て、決めた条件が、札になること。絞り込みが、すべてのズームに効くこと。
- 「すべて」が、マソンリーで開き、行ぞろえに切り替えられること。写真が、切り抜かれないこと。
- 並び順の既定が、新しい順であること(切り替えられる)。
- スライドショー・カレンダーが、動くこと。
- ドライブを外しても、この Mac で、一覧・統計・地図が見られること。原本を開くとき、接続中の場所から探すこと。
- dry-run の結果が、アルバムに含まれないこと。
- Web から、ファイルの変更・削除ができないこと。
