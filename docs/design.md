# デザイン方針

画面(Web ビューア)の見た目の方針。**デザインの正本は、この文書**。画面の動き・規則(机の配置、できごとの計算など)は、仕様書 §16 が正本。

状態の凡例: **確定** = 合意済み / **仮** = 暫定(実装時に、値をそろえる)。

## 1. 方向性 (要件: [机の配置](requirements.md#a-03))

- **ネオブルータリズム**に決定(確定)。太い黒の枠、ぼかしのない影、はっきりした色、角丸なし。
- 写真を主役にする。アルバムは、机の上に写真を並べた見た目にする(ポラロイド、付箋、テープ)。
- 比較して選んだ他の案(スイス、バウハウス、デ・ステイル、ジャポニスム)は、採用しない。

## 2. トークン(仮)

| 項目     | 方針                                                                                                            |
| :------- | :-------------------------------------------------------------------------------------------------------------- |
| 枠・影   | 黒の太い枠(3px)、ぼかしのない影(大 6px / 小 3px)、角丸なし。押すと、影のぶんだけ動く                            |
| 色の意味 | **黄=現在地・選択、ピンク=最大・強調、青=情報、緑=場所(GPS)、オレンジ=動画・注意、紫=RAW、赤=エラー・日付なし** |
| 文字     | 見出し: Dela Gothic One / 本文: Noto Sans JP / 数字・日付: JetBrains Mono                                       |
| 机       | 紙色の地に、ドット柄。ポラロイドは、白い縁(下が広い)。テープは、一部のみ                                        |
| ナビ     | 上のナビ。アルバム内は、時間の定規・検索の札・付箋のチップ                                                      |

状態の表示(未接続・結果なし・読み込み中・破損・日付不明・閲覧専用)でも、上の色の意味をそろえる。

- スタイルは、1 つのファイル(`neo.css`)にまとめる。

## 3. 余白と文字の大きさの刻み(仮)

| 項目                 | 刻み                                                                                   |
| :------------------- | :------------------------------------------------------------------------------------- |
| 余白(`gap`)          | 4 / 8 / 12 / 16 / 24 / 32 px(机の格子だけ、写真を重ねないための広い余白を使う)         |
| 文字(画面側の直書き) | 11 / 12 / 14 / 16 / 20 / 24 / 40 px                                                    |
| 見出し・数字         | クラスで決める(`.h1` 44 / `.h2` 24 / `.num` 56・38 など)。画面側で大きさを直書きしない |

## 3-1. 文字の読みやすさ(確定)

- 文字の最小は **12px**(札・補足・表の見出しは 13px、本文・表のセルは 14px)。ワイヤーフレームの 9〜12px は、1px ずつ上げた。
- 赤い札(エラーコードなど)は、**深い赤(`--r-deep` `#D63326`)に白い文字**(コントラスト比 4.8)。元の赤(`--r`)の上の白は 3.1 で足りないため。元の赤の上のボタンの文字は、黒(6.3)。黒の文字は、どの色の上でも 6.3 以上。
- 絞り込みの札は、選ぶと「✓」を付ける。赤い札は、赤のまま、太い枠も付ける。
- 薄い文字(`muted`)は、不透明度 0.75(コントラスト比 8 以上)。
- 絞り込みの欄は、ラベルも部品(札・選択欄)も、同じ大きさ(14px・高さ 44px)にそろえる。

## 4. 画面の言語

- 画面の言語は日本語。**表の見出し**と**入力欄のラベル**は、日本語にする(実行・ソース・コード・ファイルなど)。
- 各画面の上の小さな見出し(`DASHBOARD` など)は、飾りとして、英語のままにしてよい。
- 状態を表す印(`DRY-RUN`、`LIVE`、`full` などの値)は、仕様書の用語に合わせて、そのまま使う。

- **画面の見出し(`h1`)は、ふつうのタイトルだけ**にする(「ダッシュボード」「エラー一覧」「2014年4月」など)。キャッチコピーや、言い回しをひねった見出しは、使わない。ワイヤーフレームにある黄色の説明文(`note`)は、設計の注釈で、画面には出さない。

## 5. ワイヤーフレーム

- Artifact「file-seiri ネオブルータリズム」: 全画面(ダッシュボード、アルバム、地図、統計、重複比較、日付フォールバック、エラー、実行履歴)。
- アルバム: 机(年・月・できごと・すべて)、一覧、カレンダー、スライドショー、状態。
- 色・余白・文字の刻みは、ワイヤーフレームでそろえた。値は、実装のときに確定する([open-items.md](open-items.md) の「デザインの値」)。
- 画面の行き来(上のナビ)は、すべての画面でつながっている。

## 6. CLI の表示

CLI のライブ表示は、**btop 風**に決定(PoC #4。[tech-selection §10-6](tech-selection.md))。構成は、[cli-logging.md](features/cli-logging.md) §4。

- タイトルが枠線に入る、角丸のパネルを並べる。画面の幅いっぱいに広げ、端末の行数に応じて、パネルを減らす。
- **パネルの中は、濃い紺で塗る**。背景が透明な端末(iTerm2 など)でも、文字が読めるようにするため。薄い文字(`dim`)は使わず、明るい色を使う。
- 動きは、流れる印(◆)、回転する印(⠹)、処理中のバー(▰▱)、検証のハッシュの途中経過、速度のグラフ。画面の更新は、毎秒 30 回までに制限する。

## 7. 動き(Web 画面のアニメーション。仮)

Web 画面の動きには、**GSAP**(`gsap` と `@gsap/react` の `useGSAP`)を使う([tech-selection.md](tech-selection.md) §3)。実装は、Web 画面の段階で行い、ワイヤーフレームとあわせて、確認する。

### 原則

- 方向性は、ネオブルータリズムらしく、**速く、はっきり、少し弾む**。0.2〜0.5 秒、`back.out` などの弾む動き。ぬるぬる流れる動きではなく、「ポン」と置く。
- 動かすのは、`transform` と `opacity` だけ(レイアウトを動かさない。画面が重くならない)。
- 押したときの、影のぶんの移動(§2)は、CSS で行う。GSAP は、場面の動きに使う。
- GSAP は、クライアントのコンポーネントの中(`useGSAP`)だけで動かす。静的書き出しに影響しない。
- **`prefers-reduced-motion` のときは、動きを省く**(`gsap.matchMedia()` で、動きの有無を切り替える)。
- 写真が多い画面(数万枚)では、画面に見えている分だけを動かす(仮想スクロールと、あわせる)。

### ボタンの動き(確定。arcana-members の挙動に合わせる)

部品は `components/Button.tsx`、見た目と動きは `neo.css` の `.btn`。**動きは CSS だけ**(arcana-members のボタンも、CSS の `group-hover` / `group-active` と 0.1 秒の transition)。GSAP は、ボタンの文字の入れ替え(arcana-members の `SwapLabel`)や、揺れ(`shake`)など、別の動きに使う。

| 状態               | 見た目・動き                                                                                                                      |
| :----------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| 構造               | 外側 = 当たり判定と影(動かない)/ 内側の「面」だけが動く。影を本体に付けると、押した瞬間に当たり判定ごと動き、連打でちらつくため    |
| ホバー             | 面が、影の 1/4 だけ、左上へ浮く(0.1 秒)                                                                                           |
| 押す(クリック中)   | 面が、影の位置まで、右下へ沈む                                                                                                    |
| キーボード         | フォーカスは、面に、青い枠を出す                                                                                                  |
| 押せない(disabled) | 影の大きさ(`--sh`)を 0 にして、影を消し、灰色(`#c9c9c9`)の平らな面にする。カーソルは `not-allowed`                               |
| 処理中(loading)    | 押せなくして、くるくる回る印を出す。カーソルは `progress`、`aria-busy`                                                            |
| 影の大きさ         | 通常 3px、主役のボタン(`large`)6px                                                                                                |
| 動きを減らす設定   | `prefers-reduced-motion` のときは、transition を止める                                                                            |

- **カードもボタンも、同じベタの黒い影**(ネオブルータリズムの立体感)。押せるかどうかは、**ボタンのラベルの下線**と、**動き**(ホバーで浮き、押すと沈む)で見分ける。ページ移動は、ラベルに「→」も付ける。カードの影は動かない。
- 一覧から 1 つを選んで、右に詳細を出す画面(実行履歴・エラー一覧)は、**1 件ごとのボタンカード**にする。選んだカードは、黄色で、押した位置に沈んだままにする。右の詳細カードは、**白**(見やすさのため)。カードの上に、**黒い見出しの帯**を置き、各列が何かを示す(表の見出しの代わり。列の幅は、カードの中の列と、そろえる)。dry-run かどうかは、札と注意書きで示す。
- 押せるカード(要チェックなど)は、ボタンの `block` と `tone`(色の意味)で作る。
- 重複比較の採用側とスキップ側は、**間に、線と「＝」のボックス・矢印(◀)・「ハッシュ一致」の札**を置き、採用は、太い枠と、緑の「✓ 採用」のスタンプ。スキップは、グレーの画像・斜線の背景・点線の枠・大きな斜め線・「✗ スキップ ×N」のスタンプで、「ライブラリへは、コピーしていない」と添える。
- ページ移動は `href`(リンク)、ファイルの書き出しは `download`。押せないリンクは、ボタンとして出す(リンクには、無効の状態がないため)。
- 札(`chip`)を押して切り替える絞り込み(`FilterChip`)は、この動きの対象外。**選んでいるものは、黒く塗って「✓」を付ける**(色だけに頼らない)。選んでいないものは、白(意味の色は、小さな四角で添える)。

### 実装した動き(確定)

作りは arcana-members の `web/src/browser/motion` に合わせた。`web/lib/motion/`(`core`・`reveal`・`effects`・`label`)に、動きの関数を置き、`web/components/motion/` の部品が、React から呼ぶ。**動かす対象は、`data-motion` の目印で決める**(`title`・`block`・`card`・`detail-item`)。イージングは `power3.out`(弾まない)、「視差効果を減らす」では、すべて動かさず、最終の状態にする。

| 場面                           | 動き                                                                                                       | 部品                              |
| :----------------------------- | :--------------------------------------------------------------------------------------------------------- | :-------------------------------- |
| 画面を開く                     | タイトルが出て、続いて、ブロックが 0.07 秒ずつ遅れて出る                                                   | `RevealPage`                      |
| 一覧(実行履歴・エラー一覧)     | カードが、先頭の 12 枚だけ、順に出る。絞り込み・ページ送りで入れ替わるときも、同じ(`key` を変えて作り直す) | `RevealCards`                     |
| 詳細カード                     | 下から入り、中の項目が、少し遅れて、順に出る                                                               | `RevealDetail`                    |
| 数字(ダッシュボード)           | 0 から数え上がる。**数字ごとに、開始の遅れ(0〜0.35 秒)と長さ(0.65〜1.21 秒)が違う**(その数字の値と、画面での並び順から決めるので、毎回同じ)。値が変わったときは、すぐ、いまの値から | `CountUp`                         |
| 進捗バー・LIVE の点            | バーが伸びる。点が、ゆっくり脈打つ                                                                         | `GrowBar`・`PulseDot`             |
| ボタンのラベル                 | 1 文字ずつ入れ替わる(CSV を書き出したあと、「書き出しました ✓」)。下線は、ラベル全体の下に 1 本            | `SwapLabel`                       |
| 絞り込みの札の ✓               | 小さいところから、ふくらむ                                                                                 | `Tick`                            |
| 読み込みの失敗                 | 注意書きが、左右に揺れる                                                                                   | `LoadError`                       |

### 場面ごとの動き(案。それぞれの画面を作るときに足す)

| 場面                           | 動き                                                                                                    |
| :----------------------------- | :------------------------------------------------------------------------------------------------------ |
| 机(年・月・できごと)           | ポラロイドが、机の上に、少しずつ遅れて(0.04 秒ずつ)落ちて、傾きに収まる                                 |
| ズームの切り替え(年 → 月 → できごと) | 選んだ写真が、そのまま、次の机の位置へ移る(Flip)。時間の定規のつまみが、スライドする                |
| 入口                           | 「去年の今日」「今日の一枚」の札が、めくれて出る                                                        |
| 拡大表示                       | 写真が、クリックした位置から、広がる                                                                    |
| スライドショー                 | 写真の切り替えと、進行のバー                                                                            |
| 地図                           | ピンが、順に、ポンと出る。まとまり(クラスタ)の数字が、数え上がる                                       |
| 統計                           | 棒が、下から伸びる。数字が、数え上がる                                                                  |
| 重複比較                       | 採用とスキップが、左右から寄ってきて、並ぶ                                                              |
| 読み込み中                     | スケルトンの斜めの縞が、流れる                                                                          |
